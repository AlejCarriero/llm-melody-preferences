Melody listening test

About the experiment

In an experiment on whether language models have stable preferences, Claude Fable 5.2 ranked 60 short melodies it had only ever seen written as note names. This page plays them to you in a random order, with the ranking hidden, and asks how much you like each one.

Each melody lasts about seven seconds. Rate by ear, quickly, on first impression. You can replay as often as you like.
